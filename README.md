# Pokemon Randomizer

A web application that generates randomized Pokemon teams using customizable rules.

## Current Features

- Generate 3 random Pokemon
- Filter by generation
- Exclude legendary Pokemon

## Future Features

- Type filtering
- BST filtering
- Reroll options
- Shareable seeds
- Additional randomizer tools
